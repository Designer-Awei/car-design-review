# PFDBI：把视觉感觉变成可解释的判断

必须配合 [原始PDF](originals/PFDBI-framework.pdf)与 [可检索全文](originals/PFDBI-framework.txt)使用。这份说明只是操作方法，不替代原始框架。

## 五个维度

- **P / Proportion，整体比例与姿态**：车轮位置和大小、轴距/前后悬、机盖/座舱/尾部关系、宽高与重心。问“为什么看起来是这个姿态”。
- **F / Form，形体与型面**：体量、凹凸、肩部与收腰、折面、曲面连续性、高光走向。问“力量、轻盈或紧绷从什么形体里出来”。
- **D / Detail，细节与视觉层级**：灯、格栅、车窗图形、轮圈、饰件、主次与密度。问“视线先被哪里抓住，它是否服务整体”。
- **B / Brand，品牌与产品定位**：设计身份、传承、受众与产品角色。问“这台车为什么需要这样的外形”。
- **I / Innovation，审美与创新**：独特审美、有效变化、熟悉与新奇、延续与突破。问“这次设计推进了什么，形成了怎样的性格”。I 不是界面或内饰。

CMF 跨越形体、细节与品牌：同一型面在高光、哑光、浅色或深色下，会产生不同的体量阅读与情绪。工程与法规是解释造型的条件，不作为第六个缩写来凑齐。

## 三层句子

1. **形式**：后翼子板向外撑开，车门中段向内收。
2. **感知**：明暗在车轮附近集中，肩部因此显得厚实。
3. **判断**：这份力量藏在连续的体量里，静止时也有蓄力感。

一段初评可以覆盖两三个维度，也可以只把一个关系解释透。不要五句分别喊出五个维度，再用“整体协调”收尾。实测尺寸、设计师意图与功能效果需要资料；视觉印象可以直接提出，给出观察依据即可。

## 从初评到主题

视觉阶段先观察，调研阶段补身份，主题阶段找重复出现的关系。例如：

- 长机盖、后移座舱、快背都在拉长水平流动；后肩又把视线收紧 → 可以形成“舒展的力量”。
- 窄侧窗、低座舱、厚车身、收腰与鼓肩都在压实体量 → 可以形成“压缩的工业雕塑”。

同一主题也要容纳代价与偏好：前脸图形是否过密？哪种配色更能显出形体？由这些具体选择带出态度，文章才有作者，而不只是框架。

## 比较的方法

尽量使用相近角度、相同/相近版本，比较明确的变化。“老款较圆，新款较硬”之后，要继续指出转折、表面、高光或图形怎样变化。将比较结果带回当前车型，不展开另一个长篇老车评价。
